# LiDAR ParkManager — Prototype แดชบอร์ดลานจอดรถอัจฉริยะ

Prototype หน้าเว็บบริหารจัดการลานจอดรถด้วย LiDAR สำหรับทดสอบการทำงาน
สร้างด้วย **Next.js 14 (App Router) + TypeScript + Tailwind CSS** พร้อม deploy บน **Vercel**

---

## ฟีเจอร์หลัก

- **ผังลานจอดหลายแบบ** — สลับได้ 6 แบบจาก dropdown ด้านบน
  - ลานกลางแจ้ง · แถวคู่ (24 ช่อง, จอดหันหน้าเข้าหากัน + มีต้นไม้บัง)
  - ลานกลางแจ้ง · เปิดโล่ง 4 แถว (48 ช่อง, หันหน้าเข้าหากันเป็นคู่ + ต้นไม้)
  - ลานในอาคาร · 3 เกาะจอด (30 ช่อง, มีเสาอาคารบัง)
  - โรงจอดรถในอาคาร · จอดถี่ (108 ช่อง, รถชิดกันมาก + เสาโครงสร้างถี่)
  - ลานรูปตัว L (16 ช่อง)
  - ลานใหญ่ · 4 แถว (52 ช่อง, ออกแบบให้เห็น “จุดบอด” ชัด)
- **โหมดแก้ไขผัง (ปุ่ม ✏️) — ออกแบบลานจอดเอง** — เปิดโหมดแก้ไขแล้ว:
  - ลากย้ายช่องจอด เสา และต้นไม้ได้อิสระ
  - วางช่องจอดเอง แนวตั้ง (▯) หรือแนวนอน (▭) เพื่อทำมุม/เลี้ยว/เลย์เอาต์เอง
  - วางเสา (▮) / ต้นไม้ (🌳) เพิ่ม แล้วเงาบดบังจะอัปเดตตาม
  - คลิกเลือกแล้วกด Delete เพื่อลบ · กด Esc ออกจากเครื่องมือวาง
- **ลาก LiDAR ได้** — ลากไอคอนเซนเซอร์เพื่อย้ายตำแหน่ง พื้นที่ตรวจจับ (วงกลมรัศมี) อัปเดตสดทันที
- **ปรับรัศมีตรวจจับ** — ลากจุดสีฟ้าที่ขอบวงกลม หรือใช้ slider ในแท็บ “เซนเซอร์”
- **เพิ่ม / ลบ LiDAR** — ปุ่ม `＋` แล้วคลิกบนผัง เพื่อหาตำแหน่งที่คุ้มที่สุด / กด `Delete` เพื่อลบ
- **สถานะช่องจอดตามการตรวจจับ**
  - 🟢 เขียว (P) = ว่าง และ LiDAR ตรวจจับได้
  - 🔴 แดง (รูปรถ) = มีรถจอด
  - ⚪ เทา (?) = จุดบอด LiDAR มองไม่เห็น (อยู่นอกรัศมี)
- **พื้นที่ตรวจจับแบบ “ไฟฉาย” + เงา (occlusion)** — เสาอาคารและต้นไม้บดบังแนวสายตา LiDAR จริง
  พื้นที่ตรวจจับวาดเป็น visibility polygon เหมือนไฟฉาย: ส่วนที่อยู่ "หลัง" สิ่งกีดขวางจะมืด (ไม่ลงสี)
  เส้นประ = รัศมีสูงสุด, รูปทึบสีฟ้า = พื้นที่ที่มองเห็นจริง — ช่องว่างระหว่างสองอันคือ "เงา"
  ช่องจอดในเงาจะกลายเป็นจุดบอด (เทา) ทันที ผู้ติดตั้งจึงเห็นชัดว่าอุปกรณ์โดนบังตรงไหน ลองลากเซนเซอร์หามุมที่หลบเงาได้
- **รถบัง LiDAR / inter-vehicle occlusion (ปุ่ม 🚙)** — จำลองว่ารถที่จอดอยู่บังลำแสง LiDAR
  ช่องว่างที่ "ซ่อน" อยู่หลังรถ (ในมุมเฉียง/ไกล) จะกลายเป็นจุดบอด — LiDAR ไม่รู้ว่าว่างหรือเต็ม
  กดเปิด/ปิดเพื่อเทียบ เห็นชัดว่าทำไม overhead ดีกว่ามุมเฉียง (หมายเหตุ: เป็นโมเดล 2 มิติกรณีแย่สุด
  จริง ๆ การติดตั้ง overhead 4.5 ม. จะบังน้อยกว่า)
- **ปุ่มจำลองรถเข้า/รถออก (กดเอง)** — ปุ่ม “🚗 รถเข้า” เอารถ 1 คันเข้าช่องว่างที่ LiDAR เห็น,
  ปุ่ม “↩ รถออก” เอารถออก 1 คัน · ถ้าเต็มจะขึ้นป้าย “ลานเต็ม”
- **คลิกช่องเพื่อจำลองรถ** — คลิกช่องว่าง → รถขับเข้าจอด · คลิกช่องที่มีรถ → รถออก (ทดสอบทีละช่องได้)
- **แผงรายงานด้านขวา**
  - ภาพรวม: รถในลานตอนนี้, รถเข้า/ออกสะสม, อัตราครอบครอง, % พื้นที่ตรวจจับ, หมุนเวียน/ชม., เวลาจอดเฉลี่ย
  - เซนเซอร์: รายละเอียดแบบ ParkHelp (ID, Code, Name, อุณหภูมิ, จำนวนช่องที่ตรวจจับ) + ปรับรัศมี
  - เหตุการณ์: live feed รถเข้า-ออกแบบเรียลไทม์

> แนวคิดสำคัญ: ตัวเลขสถิติคำนวณจาก “สิ่งที่ LiDAR มองเห็น” เท่านั้น —
> ยิ่งวางเซนเซอร์ดี % พื้นที่ตรวจจับยิ่งสูง จุดบอดยิ่งน้อย

## รันบนเครื่อง (Local)

ต้องมี Node.js 18.18+ ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

---

## Deploy บน Vercel

วิธีที่ 1 — ผ่าน Git (แนะนำ)

1. push โฟลเดอร์นี้ขึ้น GitHub/GitLab/Bitbucket
2. เข้า https://vercel.com → **Add New → Project** → เลือก repo
3. Vercel ตรวจเจอ Next.js อัตโนมัติ กด **Deploy** ได้เลย (ไม่ต้องตั้งค่าเพิ่ม)

วิธีที่ 2 — ผ่าน CLI

```bash
npm i -g vercel
vercel        # preview
vercel --prod # production
```

## โครงสร้างโปรเจกต์

```
app/
  layout.tsx        # root layout + metadata (ภาษาไทย)
  page.tsx          # หน้าแรก -> เรนเดอร์ <Dashboard/>
  globals.css       # Tailwind + keyframe (รถขับเข้า, pulse วงตรวจจับ)
components/
  Dashboard.tsx     # คอมโพเนนต์หลักทั้งหมด (canvas + ลาก LiDAR + sim + แผงขวา)
lib/
  types.ts          # โครงสร้างข้อมูล Spot / Sensor / Layout / Event
  layouts.ts        # ผังลานเดโม่ 4 แบบ (deterministic กัน hydration mismatch)
```

---

## ปรับแต่งต่อ

- **เพิ่มผังลานใหม่** — เพิ่ม object ใน `lib/layouts.ts` (ใช้ helper `rowV` / `colH`) แล้ว push เข้า `LAYOUTS`
- **เชื่อมข้อมูลจริง** — แทนที่ state `spots` ใน `Dashboard.tsx` ด้วยข้อมูลจาก API/WebSocket
  (เช่น gRPC/MQTT จากเซนเซอร์จริง) โครงสร้าง `Spot.occupied` ใช้ได้เลย
- **รูปทรงพื้นที่ตรวจจับ** — ปัจจุบันเป็นวงกลมรัศมี แก้ฟังก์ชัน `isCovered()` เป็นมุมเซกเตอร์ได้ถ้าต้องการ
